Methodology & data sources

What this local build is

This is the fully local MVP of racetotur.in. It runs the production pipeline — HTML parser, snapshot validation, versioned qualification policy, and server-rendered UI — against a local HTML file instead of a live fetch. The process makes zero network requests: the configured fixture stands in for the public ATP Live Race to Turin page. {{ notice }}

Where each number comes from

  • Rank, movement, points, tournament state, next, max: parsed from the fixture ({{ source }}) by parser {{ parser_version }}, exactly as a live scraper would parse the public page. Displayed totals are treated as source facts; nothing is reconstructed or estimated.
  • Official qualifiers, Grand Slam titles, withdrawals: a small curated file, because officially announced status must never be inferred from points.
  • Provisional selection: ruleset {{ ruleset }} applied to the parsed table: top seven by race rank, then up to two current-year Grand Slam champions ranked 8–20 by rank, then everyone else in rank order; the first eight unique players are selected and the ninth is the first alternate.

Accuracy and freshness

Every page shows the source timestamp, the generation timestamp, and the source age. When the source age exceeds the configured threshold the page is labelled stale — last known good rather than pretending to be live. A candidate snapshot that fails structural validation (missing heading, implausible row count, duplicate ranks or identities, unparseable or non-monotonic points) is rejected wholesale and can never replace the last verified snapshot.

Unavailable values

When the source displays no “next” or “max” value — a player is eliminated or not entered this week — the field is shown as unavailable with the reason, never as an estimate.

Independence

racetotur.in is an independent, noncommercial fan project with no affiliation to the ATP. The production design reads only the public race page at a modest global cadence with an honest user agent and a one-command kill switch; this local build removes even that and reads only local files.
